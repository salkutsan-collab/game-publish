# Путь двойника

Обучающая веб-игра по курсу «Цифровые двойники изделий» (ПИШ СПбПУ
«Цифровой инжиниринг», автор курса - А.И. Боровков).

Слушатель в роли инженера строит цифровой двойник изделия (авиадвигатель, ГТД) -
от постановки задачи до полномасштабной эксплуатации. На каждом этапе нужно
понять, что сделать, из чего выбрать, чем обосновать решение и какие инструменты
для этого понадобятся. Ошибки не блокируются, а отзываются последствиями позже.

## Что это за версия

Это **вертикальный срез** - первые главы для проверки замысла и ощущения от игры:

- Пролог · Назначение
- Акт 1 · Что такое двойник (различение двойник / тень / модель / маркетинг)
- Акт 2 · Матрица требований и целевых показателей
- Акт 3 · Система моделей (дерево моделей, обеспечение мощностями)
- Акт 4 · Верификация (диагностика расчета)
- Акт 5 · Валидация (сверка с натурным экспериментом)
- Акт 6 · Парк стендов (кампания виртуальных испытаний)
- Акт 7 · Платформа (наведение порядка: ядро SPDM, по образу CML-Bench)
- Акт 8 · Опытный образец (протокол натурных испытаний - момент истины, ЦД-Р)
- Акт 9 · Производство (обмер геометрии, технологическая наследственность, ЦД-П)
- Акт 10 · Эксплуатация (датчики, двусторонние связи, инцидент, ЦД-Э)

Дальше по плану - финал (экономический эффект, защита проекта,
следующее поколение изделия - полномасштабный цифровой двойник).

## Как играть

Откройте сайт по ссылке GitHub Pages (или дважды кликните `index.html` локально).
Впишите имя, нажмите «Начать проект». Прогресс сохраняется автоматически в
браузере - можно закрыть вкладку и продолжить позже.

## Технически

Статичная веб-страница без сервера: HTML + CSS + JavaScript. Сюжет вынесен в
данные (`story.js`), движок - `engine.js`. Картинки пока на заглушках.
